The German LSTM language data is from https://github.com/naptha/tessdata/blob/gh-pages/4.0.0_fast/deu.traineddata.gz (Apache-2.0, Tesseract contributors).

The build copies the worker and self-contained WebAssembly runtimes from the npm dependencies tesseract.js and tesseract.js-core (Apache-2.0). No document data or language downloads are sent to an external service at runtime.
